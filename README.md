# GreenCharge-AI：电动汽车充电场站负荷诊断与碳普惠核算系统

本项目面向新能源汽车充电场站数据分析与绿色低碳管理场景，基于 Python + Streamlit + Plotly 构建。

## 核心功能

1. **多场站负荷特征分析**：支持对多个充电场站 24 小时充电订单、功率负荷及峰谷电量结构进行可视化诊断。
2. **碳普惠减排量动态核算**：结合绿色交通度电减排因子，自动核算场站与车主充电行为产生的碳减排资产。
3. **AI 错峰调度与碳积分策略**：针对高负荷时段自动生成“价格引导 + 碳积分双轮驱动”的有序充电策略。

## 快速开始

需要 Python 3.9 以上。

```bash
pip install -r requirements.txt
streamlit run app.py
```

启动后浏览器会自动打开 `http://localhost:8501`。

## 数据格式

上传 CSV 时可包含以下列；不上传则使用内置的 3 个场站模拟基准数据。

| 列名 | 说明 |
| --- | --- |
| `场站名称` | 充电场站标识 |
| `充电开始小时` | 0–23 的整数 |
| `充电量_kWh` | 该次充电的电量 |
| `充电时长_分钟` | 充电时长 |
